# Python Activity-Based Learning

This folder contains 10 beginner-level case studies selected from the supplied assignment PDF.

## Files
- `Python_Activity_Assignment.docx` — assignment write-up with problem statements, objectives, assumptions, algorithms, flowchart descriptions, pseudocode, sample outputs, test cases and conclusions.
- `01_...py` through `10_...py` — separate runnable Python programs.

## How to run
1. Install Python 3.
2. Open Command Prompt or a terminal in this folder.
3. Run a program, for example: `python 01_electricity_billing.py`
4. Enter the requested values.

## Important
The source PDF lists case-study topics and required deliverables, but does not prescribe numerical tariff slabs, pass thresholds, discounts or sample datasets. Where needed, this project states illustrative assumptions. Replace them if your faculty gives specific values.

Capture actual screenshots after running each program; sample outputs in the document are illustrative, not screenshots of execution.
